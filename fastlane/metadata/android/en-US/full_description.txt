The Cockpit interface and features shown here ship in Bolt 1.02.0 and newer. Download the latest signed APK from GitHub and check its release notes.

Bolt is an open-source kernel flasher for rooted Android devices. Choose a compatible script-based AnyKernel ZIP, review the device and recovery plan, and run the package’s original installer. Receiving or sharing a ZIP never starts flashing automatically.

The Cockpit brings Overview, Recovery and Activity together:
• Device information and a clear next step.
• Automatic snapshots of discovered supported recovery targets before installation.
• One compact recovery card per bundle, with partition badges and original image details.
• Manual backups through Android’s document picker.
• Manifest checks for device identity, target capacity and image digests before restore writes, followed by readback verification.
• Retained operation results, readable provider messages and full raw log export.
• Separate installer completion, device restart and your health feedback.
• Asgardian light/dark themes, AMOLED mode, Android 12+ dynamic colors, and Outfit/Fira Code or system fonts.

Requires Android 7.0 or newer, working root access and a kernel package designed for your exact device and firmware. Kernel flashing can cause bootloops or data loss. Keep off-device backups and a working recovery route. Automatic recovery covers discovered targets and cannot capture every change a root installer might make. App-private snapshots are lost when app data is cleared or Bolt is uninstalled.

Raw image flashing, KernelSU LKM installation and inactive-slot OTA preparation are not implemented. Device support depends on the package, firmware and root environment; see the repository’s validation notes.

Bolt has no advertising or analytics SDKs. Third-party kernel scripts execute as root and can independently access files or the network. Review exported logs before sharing them publicly.
